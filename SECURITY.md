# Security

Do not disclose real clipboard data, private hostnames, credentials or signing material in public issues. Use GitHub private vulnerability reporting for this repository if enabled. Its activation remains maintainer setup; no reporting email is invented. If private reporting is unavailable, contact the repository owner through their published GitHub profile before sharing sensitive details.

No production release/support window exists yet. Review main for current fixes. Threat boundaries and race limitations are documented in docs/architecture.md and docs/privacy.md. Do not attach general pasteboard dumps to reports.
