# RefPaste product requirements

RefPaste is an offline Swift menu-bar application for macOS 15+, distributed as a universal arm64/x86_64 app. Preserve repository `mamachanko/pink` and its existing MIT ownership. No third-party application runtime dependencies, telemetry, accounts, network lookups, history, scripts, global shortcuts, destination detection, keyboard interception, or updater.

A copied supported URL becomes ONE pasteboard item: byte-exact original UTF-8 plain text, escaped HTML hyperlink, native RTF hyperlink, compatible URL metadata, private versioned self marker and autogenerated marker. Receiver selects format. Rich label is owner/repo#number for GitHub issues/pulls; full namespace/project#number for GitLab issues or !number for merge requests. Target retains original query, fragment, spelling and case.

Default hosts github.com and gitlab.com, HTTPS. GitHub paths /owner/repo/pull/N and /issues/N; review suffixes files, commits, checks. GitLab /namespace/project/-/merge_requests/N or /issues/N; merge-request suffixes diffs, commits, pipelines. Trailing slash supported. Reject other suffixes. Enterprise rules specify service, exact hostname, optional port and installation prefix, enabled state, and per-private-host HTTP opt-in. Validate configuration and reject overlapping enabled rules.

Accept exactly one absolute URL, at most 8192 UTF-8 bytes. Reject whitespace/prose, multiple lines, markdown/HTML, credentials, unknown/lookalike hosts, unsupported schemes, malformed escapes, encoded path separators, controls/bidi controls, invalid/zero/non-ASCII object numbers. Validate decimal strings without integer conversion. Normalize matching keys only. Preserve namespace/repository display case. Additional route support requires documented justification and tests.

Monitor changeCount with an injected scheduler (~200 ms, tolerance); baseline on start, resume, wake and permission recovery. Do not transform existing contents except explicit Format current clipboard. Inspect item count/types before data reads. Skip multiple items, files/images/promises, unknown semantic types, concealed/transient/autogenerated/password-manager markers, remote clipboard, named existing links, conflicting URL/text. Document compatible type allowlist. Avoid materializing arbitrary lazy data. Construct all data before mutation; check generation after read and immediately before write; no suspension in clear/write window. No atomic compare-and-swap claim. Self writes must not loop or hide later copies. Failure must not repeat mutations or roll back over newer data.

Restore only while last transform still owns current clipboard. Keep one bounded memory-only snapshot; invalidate on external change, pause, exit. No persisted clipboard contents. Restore cannot change earlier pastes. Immediate paste can beat polling; original URL is safe fallback.

Before monitoring, explain local processing and offer Enable/Not now. Distinct Paused, Active, Permission needed, Error. Use available privacy APIs with guards, avoid repeated permission prompts; retry only by user. No Accessibility/Input Monitoring/Screen Recording permissions. Native icon, no Dock icon. Menu: automatic formatting toggle, Format, safe Restore, Settings, About, Quit. Settings: host CRUD, automatic formatting, opt-in SMAppService.mainApp login registration with actual approval state. Versioned local settings fail safely. Keyboard/VoiceOver/light/dark/focus support. About version/build/license/repository/releases. Diagnostics only state/category, no content or reversible identifiers.

Deliver source, portable and native tests, resources/metadata/icons, XcodeGen, genuine tool/dependency locks, scripts and make bootstrap/doctor/lint/test/build/package/verify, repository templates/security/contribution/ownership/Renovate and operational agent instructions. Required docs: specification, architecture, privacy, release, repository setup, compatibility, acceptance, verification. Release notes are GitHub Releases; no changelog/version commits. Never fabricate screenshots or verification.

Reusable verification workflow: formatting/static/workflow/shell checks, portable/release tests, native AppKit tests on Apple Silicon and Intel where supported, universal build, ad-hoc package verification. Exact Xcode pinned; print architecture/toolchain. Read-only secret-free fork CI; no pull_request_target. Full action SHAs, stable required aggregate fails on failure/skip. Document remote settings without silently applying them.

Actual semantic-release on main, tags v${version}, private npm package; compatible exact plugins/preset. fix/perf patch, feat minor, breaking (including ! and footer under any type) major; ordinary docs/test/chore/ci none. Initial qualifying release 1.0.0. Complete history/tags, serialized non-cancelling publication, exact-commit verification, publishing-only write access and GITHUB_TOKEN. Prepare uses nextRelease.version; no dry-run version scraping or tag-trigger workflow.

Assets: versioned ZIP and drag-to-Applications DMG, SHA256SUMS, build-info.json. Inject stable marketing version, numeric build, source commit without changing tracked source. Manifest: architectures/minimum OS/toolchain/signing/notarization/CI identity. Verify extracted/mounted apps, layout, executable, versions, architectures, signatures/checksums and clipboard-free launch/exit smoke mode. Default ad-hoc labelled “Ad-hoc signed; not Developer ID signed; not notarized.” Developer ID requires complete real credentials, temporary keychain, hardened runtime, timestamp, minimal entitlements, notarytool, staple, tickets/Gatekeeper assessment, cleanup on success/failure, final checksums. Failure prevents publication; explicit asset allowlist; verify published assets/commit; document partial-publish recovery without tag rewriting or replacing known-good releases.

Tests must use unique named pasteboards, injected clocks, no general clipboard/permissions/login mutations. Cover routes, enterprise/nesting/case/ports/prefixes/queries/fragments, adversarial input, exact plain text, HTML escaping, RTF link round trip, one-item serialization, markers/types/named links/conflicts, self/identical/rapid/external changes, restore staleness, startup/pause/permissions/read/write/settings failures. Actual release config tests use temporary Git repos for initial/patch/minor/major/none/breaking and preparation/signing/assets/cleanup/recovery; fixed version macOS packaging is separate from dry run.

Manual compatibility records must include OS/app/browser versions/date/label/target/outcome after saving/sending: Mail rich/plain, Slack desktop/web, Chat Chrome/Safari, Terminal, plain editor, paste without formatting, optionally iTerm2/history app. Unavailable = NOT RUN. No rich-text-support inference.

Work on feature branch, Conventional Commits, push/PR/checks when authorized access works. Do not merge, force-push, publish manually, change visibility/protections or purchase. Finish independent work despite blockers. Final delivery distinguishes implemented work from PASS/FAIL/NOT RUN/BLOCKED verification, artifacts/signing/PR/setup/unmet criteria.
